Mi Despensa

Aplicación de gestión de despensa desarrollada en Python

Mi Despensa es un proyecto personal desarrollado en Python cuyo objetivo es facilitar la organización y el control de los productos de una despensa doméstica.

La aplicación permite trabajar con productos, cantidades y categorías, además de gestionar una lista de la compra.

Funcionalidades

- Gestión de productos de la despensa.
- Control de cantidades.
- Organización de productos por categorías.
- Gestión de la lista de la compra.
- Almacenamiento de información mediante archivos JSON.

Tecnologías utilizadas

- Python: lenguaje de programación.
- JSON: almacenamiento y gestión de datos.
- Visual Studio Code: entorno de desarrollo.

Estado del proyecto

Proyecto personal en desarrollo, creado para poner en práctica y ampliar conocimientos de programación con Python.
